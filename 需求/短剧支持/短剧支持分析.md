# 短剧支持与沉浸式竖屏控制方案分析报告

## 1. 核心目标
为短剧打造一套完全独立的沉浸式控制系统，实现类似“红果短剧”或“抖音”的交互体验。核心逻辑是**重交互、轻装饰、强沉浸**。

## 2. 架构设计：解耦与切换
### 2.1 独立控件类
- **现有类**：`MobilePlayerControls` (主要负责横竖屏旋转适配、传统播放体验)。
- **新增类**：`ShortDramaControls` (专用竖屏沉浸式交互)。
- **逻辑分发**：在 `VideoPlayerWidget` 中，根据 `isVerticalVideo` (通过宽高比判断) 或 `currentDetail.isShortDrama` (标签判断) 决定渲染哪个控件。

### 2.2 核心组件拆解
1. `ShortDramaGestureLayer`：手势拦截层，处理单击暂停动画、边缘倍速、中心长按设置、上下滑动切集。
2. `ShortDramaProgressBar`：定制进度条，实现播放/暂停状态下的颜色与高度变化，以及拖拽时的无边框预览。
3. `ShortDramaSettingsSheet`：沉浸式底栏与设置面板。
4. `ShortDramaDanmakuModule`：全新的弹幕配置与列表 UI。

## 3. 交互逻辑详析

### 3.1 播放/暂停反馈
- **视觉反馈**：单击屏幕暂停时，屏幕中心出现 0.5 透明度的三角图标，执行“由大变小”的缩放动画。
- **状态同步**：再次点击图标消失，视频无缝继续播放。

### 3.2 智能进度条 (TikTok Style)
- **静态状态**：
    - 暂停：橙色高亮，增加粗度（显眼）。
    - 播放：白色半透明，高度减半（减少遮挡）。
- **拖拽状态**：
    - 高度显著增加。
    - 在进度条上方 40px 处，纯文字显示 `xx:xx / xx:xx`，无背景框。
    - **逻辑增强**：若暂停时拖拽，松开手指即视为“确认调整”并立即播放。

### 3.3 手势分区逻辑
- **边缘区 (左右各 10%)**：检测长按，触发 2x 倍速，松开恢复。
- **内容区 (中心 80%)**：
    - 上下滑动：触发切集动画。
    - 长按：弹出底栏设置（倍速、收藏、投屏等）。
    - 单击：播放/暂停。

### 3.4 切集动画实现
- 使用 `PageView.builder` 配合 `scrollDirection: Axis.vertical`。
- **切集策略**：滑动切换时**不记录**旧集数的播放位置，确保短剧的快速连贯性。
- **动画效果**：通过 `PageTransformer` 实现类似翻书或抖音的卡片推移感。

## 4. UI 细节复刻 (Lucide 图标库)
- **底栏框**：100% 宽度，20px 外边距，纯黑背景，包含 `选集 · 共 xx 集` 和 `LucideIcons.chevronUp`。
- **全屏切换**：在选集框右侧加入 `LucideIcons.maximize` / `LucideIcons.minimize`。
- **设置面板**：
    - 收藏、投屏、小窗按钮。
    - **弹幕联动**：开关状态实时改变右侧的“设置”按钮入口。
    - **弹幕设置**：百分比滑动条（不透明度）、分级文字选择（大小、速度、行数）。
    - **弹幕列表**：时间轴 + 内容的极简列表，白色风格。

## 5. 适配方案：竖屏小窗 (PiP)
- 开启小窗时，检测视频比例。
- 调用原生 PIP 参数，强制申请竖屏比例（如 9:16），避免传统小窗的黑边问题。
