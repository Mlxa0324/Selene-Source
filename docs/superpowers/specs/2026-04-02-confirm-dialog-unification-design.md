# 公共确认弹框统一设计

日期：2026-04-02

## 背景

当前项目里的危险确认弹框有两套实现：

- `continue_watching_section.dart`、`search_screen.dart` 使用自定义大卡片确认框
- `download_screen.dart`、`player_download_panel.dart` 仍使用原生 `AlertDialog`

结果是样式不统一，尤其 `取消` 按钮在浅色和深色模式下都缺少明确边框，视觉上像“没有按钮”。下载管理中的删除确认也没有复用已有的大卡片确认框。

## 目标

- 新增一套公共确认弹框组件和展示 helper
- 统一危险操作的确认样式
- `取消` 按钮在黑白模式下都具备清晰边框
- 下载管理页面和播放器下载面板删除/取消下载确认全部迁移到公共确认框

## 范围

首批统一以下场景：

- `lib/widgets/continue_watching_section.dart`：清空播放记录
- `lib/screens/search_screen.dart`：清空搜索历史
- `lib/screens/download_screen.dart`：删除任务、批量删除
- `lib/widgets/player_download_panel.dart`：删除缓存、取消下载

不在本次范围内：

- 普通信息提示类弹框
- 非危险操作的选择型弹框
- 所有 `AlertDialog` 的一次性全量替换

## 方案

### 公共组件

新增一个公共确认弹框组件与调用 helper，例如：

- `AppConfirmDialog`
- `showAppConfirmDialog(...)`

参数包含：

- 标题
- 描述
- 图标
- 主按钮文案
- 次按钮文案
- 是否危险操作
- 确认回调

### 视觉规范

- 浅色模式：白底卡片
- 深色模式：深灰底卡片
- 圆角保持当前大卡片确认框风格
- 顶部保留圆形图标容器
- 标题与描述居中
- 主按钮：实心危险色
- 次按钮：统一改成 outline 样式
  - 浅色模式：浅灰描边
  - 深色模式：半透明亮色描边

### 交互规范

- 点击次按钮：直接关闭弹框
- 点击主按钮：先关闭弹框，再执行确认回调
- 默认文案继续使用当前业务语义，例如 `清空`、`删除`、`全部删除`、`取消下载`

## 实现边界

- 新增公共 dialog 文件，承接所有危险确认框样式
- 业务文件只保留文案和行为，不再内嵌重复的 `AlertDialog` UI 结构
- 不修改各业务动作本身，只替换展示层

## 测试

新增或更新 widget test，覆盖：

- 公共确认框在浅色/深色模式下能正确渲染
- `取消` 按钮具备描边样式
- 下载管理删除确认改走公共确认框
- 播放记录/搜索历史清空确认改走公共确认框
