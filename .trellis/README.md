# Trellis 项目知识库

本目录用于沉淀 Selene 项目的需求、实现规格和开发检查清单，方便后续继续由人和 AI 协作迭代。

## 目录结构

- `requirements/`：产品需求、交互需求、验收口径。
- `spec/frontend/`：Flutter 前端实现规格、组件边界、测试点。
- `spec/guides/`：开发前需要快速检查的思考清单。
