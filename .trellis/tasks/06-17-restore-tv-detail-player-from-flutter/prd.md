# PRD: 从 Flutter TV 1:1 还原详情页与播放页

## 目标

将 Kotlin TV 的详情页 (`TvDetailRoute`) 和播放页 (`TvPlayerRoute`) 对齐 Flutter TV 端 (`tv_video_detail_screen.dart` / `player_screen.dart`) 的交互和视觉。

## 详情页现状 vs 目标

| 维度 | 当前 Kotlin TV | Flutter TV（目标） |
|------|---------------|-------------------|
| 预览区 | 静态海报卡片 (420×236dp) | 16:9 视频播放器，自动开始播放 |
| 全屏入口 | 无 | "全屏"按钮，点击进入全屏覆盖层 |
| 收藏按钮 | 无 | "收藏"按钮，心形图标 |
| 选集分组 | 无分组，所有集数横向滚动 | 50集一组，底部二级 group 选择器 |
| 恢复记录 | 无 | 检查续播记录，弹出续播提示 |
| 加载态 | `TvStatePanel(Loading)` 面板 | 骨架屏 |
| 元信息 | 年份/来源/集数 pill | 相同 + 简介文本 (最多6行) |
| 推荐 | `TvPosterRail` | 相同 |
| D-pad 焦点 | Compose 默认 | 焦点记忆 + EdgeShake 动画 |

## 播放页现状 vs 目标

Kotlin TV 播放页已覆盖 Flutter TV 大部分功能，差距较小：

| 维度 | 当前 Kotlin TV | Flutter TV（目标） |
|------|---------------|-------------------|
| 底部菜单 | 5 tab 可用 | 5 tab |
| 线路切换 | 占位 chip（待接入） | 真实线路列表 + 测速结果 |
| 选集面板 | 占位 chip | 分组选集列表 |
| 画面比例 | 已对齐 | 已对齐 |
| 倍速 | 已对齐 | 已对齐 |
| 片头/尾跳过 | 已对齐 | 已对齐 |
| 弹幕开关/手动匹配 | 已对齐 | 已对齐 |
| 进度条缓存段 | 已对齐 | 已对齐 |
| 中心播放按钮 | 已对齐 | 已对齐 |

播放页仅需补齐：**线路切换接入真实数据**、**选集面板支持分组**。

## 验收标准

### 详情页
- [ ] 预览区显示 16:9 视频播放器，自动续播或从头播放
- [ ] "全屏"按钮可点击，点击后进入全屏覆盖层（复用同一个 player controller）
- [ ] "收藏"按钮可收藏/取消收藏
- [ ] 选集超过 50 集时分 group 显示，底部有 group 切换行
- [ ] 有续播记录时弹出续播提示（"从第X集继续？"）
- [ ] 首次加载显示骨架屏，非加载面板
- [ ] 简介文本最多 6 行，超出省略

### 播放页
- [ ] 线路菜单展示真实 source 列表
- [ ] 选集菜单展示真实 episode 列表（支持分组）
