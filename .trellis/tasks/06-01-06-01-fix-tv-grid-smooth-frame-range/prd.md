# 修复 Flutter TV 纵向列表平滑外框范围异常

## Goal

修复 TV 纵向 Grid 在平滑外框模式下焦点框短暂包住标题副标题、再回到封面的异常切换效果。

## Requirements

- 仅修复 TV 端 `smoothFrame` 平滑外框模式下的纵向 Grid 焦点框范围与过渡问题，不改放大镜模式。
- 纵向 Grid 共享焦点框在切换卡片、滚动列表和焦点回到封面时，都只能跟随封面区域，不能短暂包住标题和副标题。
- 保留平滑外框模式现有的平滑移动体验，不把共享外框退化成瞬移或直接关闭。
- 不影响首页横向分区、搜索推荐横向列表和普通卡片模式的焦点效果。

## Acceptance Criteria

- [ ] 平滑外框模式下，纵向 Grid 在卡片之间切换时，共享焦点框尺寸始终等于封面尺寸加外扩边距，不会扩展到标题副标题区域。
- [ ] 平滑外框模式下，纵向 Grid 在滚动过程中，共享焦点框仍然稳定贴合当前封面，不出现明显“先包整卡再回到封面”的回弹观感。
- [ ] 放大镜模式不受影响。
- [ ] 至少新增或更新 1 个 widget test 覆盖平滑外框模式下的封面对齐行为。

## Notes

- 这是轻量 TV 焦点行为修复，PRD-only 即可。
- 本次不处理首页横向分区焦点记忆、播放器 rail 焦点记忆等其它任务。
