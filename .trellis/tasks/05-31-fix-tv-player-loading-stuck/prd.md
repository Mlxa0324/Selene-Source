# 修复 Flutter TV 播放器转圈不消失

## Goal

修复 Flutter TV 端播放器 loading 转圈状态偶发残留问题，避免用户进入进度详情页或全屏长按快进后，播放已恢复但界面仍显示转圈。

## What I already know

- 用户反馈进入进度详情页时，播放器上的转圈偶尔不会自动消除。
- 用户反馈全屏长按快进后，播放器上的转圈偶尔不会自动消除。
- 该问题属于播放器 UI 状态与播放/缓冲状态不同步的缺陷。

## Assumptions

- 修复范围优先限定在 Flutter TV 端播放器页面、控制层或状态同步逻辑。
- 不改变现有播放内核、接口协议和业务导航结构。
- 若无法稳定复现，则通过状态流、事件订阅、生命周期和相似代码对比定位根因。

## Requirements

- 进入进度详情页后，播放器 loading 转圈必须在播放状态恢复、缓冲结束或页面状态完成后自动消失。
- 全屏长按快进结束后，播放器 loading 转圈必须随 seek 完成、播放恢复或缓冲结束自动消失。
- loading 展示条件必须有明确退出路径，避免因缺失事件、焦点操作、页面切换或长按交互导致状态卡住。
- 保持 TV 遥控器交互、全屏控制层、快进逻辑和现有播放体验不回退。
- 优先补充针对 loading 状态恢复的单元测试、组件测试或可执行验证。

## Acceptance Criteria

- [x] 进度详情页场景下，播放恢复后 loading 不再长期残留。
- [x] 全屏长按快进场景下，长按结束并完成 seek 后 loading 不再长期残留。
- [x] loading 状态在播放、暂停、缓冲、seek、页面进入/退出等关键状态切换中有确定的清理逻辑。
- [x] 相关 Flutter 分析或测试通过。
- [x] 变更不引入播放器控制层明显闪烁、焦点丢失或遥控器操作回退。

## Out of Scope

- 不重构播放器内核。
- 不调整非 TV 端播放器体验，除非代码复用导致必须同步修复。
- 不改动后端播放进度接口。

## Technical Notes

- 待检查 Flutter TV 播放器页面、进度详情页、全屏控制层、seek/long press 处理和 loading overlay 展示条件。
