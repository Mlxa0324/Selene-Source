# 修复 Flutter TV 首页焦点返回位置丢失

## Goal

首页热门电影等横向内容区离开后再返回时，焦点应恢复到上次离开的卡片位置，而不是重置到第一个。

## Requirements

- 首页各横向内容分区需要记住本分区最后一次获得焦点的卡片位置。
- 用户从“热门电影”倒数几个卡片向下移动到“热门剧集”后，再向上返回“热门电影”时，需要回到离开前的卡片，而不是默认第一个卡片。
- 焦点记忆需要按分区隔离，不能把“热门电影”的位置错误套用到“热门剧集”等其它分区。
- 当分区数据刷新、数量变少或上次位置不存在时，可以回退到该分区当前可用的最后一个或第一个卡片，避免焦点落空。
- 保持首页顶部导航、继续观看、空分区跳过等既有焦点行为不回退。

## Acceptance Criteria

- [ ] 首页“热门电影”横向列表移动到非首个卡片后，向下进入“热门剧集”，再向上返回时焦点恢复到离开前的“热门电影”卡片。
- [ ] 首页不同横向分区分别维护自己的最近焦点位置。
- [ ] 分区数据为空或数量不足时，焦点恢复逻辑不会抛异常，也不会请求不存在的卡片。
- [ ] 相关 widget test 覆盖上述焦点返回行为。

## Notes

- 这是轻量焦点行为修复，PRD-only 即可。
- 本次不处理详情页、播放器、顶部导航之外的新焦点策略。
