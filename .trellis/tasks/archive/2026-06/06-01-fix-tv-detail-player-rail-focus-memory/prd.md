# 修复 Flutter TV 详情和全屏横向列表焦点记忆

## Goal

详情页和全屏播放页的横向滚动列表在上下切换焦点后，应恢复到用户上次停留的卡片位置，不再自动归位或主动滚动到开头。

## Requirements

- 详情页所有横向滚动列表需要记住本列表最后一次获得焦点的卡片位置。
- 全屏播放页所有横向滚动列表需要记住本列表最后一次获得焦点的卡片位置。
- 用户在横向列表移动到倒数第二个、最后几个或任意非首个卡片后，向下离开再向上返回时，焦点必须恢复到离开前的卡片。
- 焦点恢复时不得主动把横向列表滚动到第一个，也不得由页面刷新、焦点切换或程序逻辑强制归位。
- 不同横向列表之间的焦点记忆需要隔离，剧集、推荐、线路、播放控制等区域不能互相污染位置。
- 当列表数据刷新、数量变少或上次位置不存在时，可以夹取到当前最后一个可用卡片，避免焦点落空。
- 保持遥控器方向键、确认键、返回键、详情页播放入口、全屏播放器现有播放控制行为不回退。
- 优先复用现有 TV 焦点组件和列表模式，避免为相同焦点记忆逻辑新增重复实现。

## Acceptance Criteria

- [x] 详情页横向列表移动到非首个卡片后，向下离开再向上返回时焦点恢复到离开前的卡片。
- [x] 全屏播放页横向列表移动到非首个卡片后，向下离开再向上返回时焦点恢复到离开前的卡片。
- [x] 横向列表恢复焦点时不主动滚动到首项，不出现肉眼可见的自动归位。
- [x] 多个横向列表分别维护自己的最近焦点位置。
- [x] 列表为空、数据变短或焦点索引越界时不抛异常。
- [x] 相关 widget test 覆盖详情页和全屏播放页焦点返回行为。
