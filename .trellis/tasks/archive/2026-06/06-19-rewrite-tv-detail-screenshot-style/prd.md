# 按截图重做 Kotlin TV 详情页样式

## Goal

把当前 Kotlin TV 详情页 UI 推翻重做，按用户提供的两张截图上下拼接后的完整详情页样式实现。逻辑继续沿用 Flutter TV 详情页契约和前两阶段已完成的 Kotlin 状态机/展示策略，不在旧 UI 私有组件上继续局部修补。

## Requirements

- 详情页 Route 必须按截图重新组织，不沿用上一阶段的 `IvyTV` 风格顶部栏、普通 Hero、普通芯片样式继续微调。
- 顶部栏：
  - 左侧品牌显示“网飞猫”。
  - 品牌右侧显示说明文案：`按返回键返回上一页 | 全屏时[向下键]可进行播放设置（内核，倍数，其它）`。
  - 右侧显示搜索胶囊按钮、登录胶囊按钮和当前时间。
- Hero：
  - 左侧为超宽 16:9 预览播放器区域，尺寸接近截图上半页左侧大画面。
  - 右侧为标题、红色豆瓣评分标签、年份、地区、类型标签、灰色简介框和“更多”按钮。
  - 操作按钮为三枚大方块：全屏、收藏、反馈；当前焦点使用红色底和白色描边。
- 线路：
  - 标题为 `切换线路`，后接灰色说明文案。
  - 横向线路卡为大矩形，选中/获焦为红色，其余为灰色。
  - 支持卡片顶部角标，例如“待加速”；主标题展示 `线路名(集数)`，副标题展示线路描述。
- 选集：
  - 标题为 `选集(共X集全)` 或等价集数文案。
  - 选集分组区顶部有灰色轨道和当前红色进度段。
  - 分组标签在轨道下方，当前分组红色，其余白色/灰白。
  - 保持 20 集分组策略，但截图样式中按可见区间展示。
- 推荐：
  - 标题为 `好片推荐`。
  - 海报使用浅色占位/封面大卡片，下方显示剧名，卡片底部展示集数状态。
  - 横向滚动和焦点行为保留前一阶段实现。
- 底部：
  - 居中显示两个胶囊按钮：`返回顶部`、`随便看看`。
  - 底部弱提示：`按遥控器[返回键]回到顶部导航`。
- 焦点：
  - 保留前一阶段显式焦点图语义，视觉焦点改成截图里的红底/白框。
  - 搜索、登录、播放器、全屏、收藏、反馈、线路、选集分组、推荐、底部操作之间必须有明确上下目标。
- 逻辑：
  - 不改坏 Flutter TV 同款状态机：精确源/标题补源、无源完成空态、推荐为空隐藏多余底部、当前源/当前集选择等行为保持。
  - 本任务优先改 UI；播放记录/退出收尾仍由后续子任务处理。

## Acceptance Criteria

- [ ] `TvDetailRoute.kt` 视觉结构整体替换为截图式组件命名和布局，不只是调整旧组件颜色。
- [ ] 顶部栏包含“网飞猫”、说明文案、搜索、登录和时间。
- [ ] Hero 左侧播放器 + 右侧标题/标签/简介/三按钮布局符合截图。
- [ ] 线路区使用截图式大矩形线路卡，红色当前项/灰色普通项。
- [ ] 选集分组区包含顶部轨道、红色当前段和区间标签。
- [ ] 推荐区标题为“好片推荐”，海报卡样式接近截图。
- [ ] 底部显示“返回顶部”“随便看看”和返回键提示。
- [ ] 新增或更新源码契约测试，锁定截图关键文案、组件和样式入口。
- [ ] `./re-android/gradlew -p re-android :feature-tv-detail:testDebugUnitTest` 通过。
- [ ] `git diff --check -- <task files>` 通过。

## Out Of Scope

- 不在本任务里完成详情播放记录保存、退出高优先级打断、全屏共享播放会话收尾。
- 不做截图像素级自动比对；以结构、尺寸比例、颜色、文案和焦点状态接近为验收。
- 不重做非详情页。
