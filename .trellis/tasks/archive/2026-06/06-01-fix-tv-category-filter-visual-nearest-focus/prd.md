# 修复 TV 分类筛选相邻行视觉就近焦点

## Goal

分类筛选面板相邻行上下移动时，焦点按屏幕上的横向视觉位置就近落点，而不是按当前选项序号移动到下一行相同序号。

## Requirements

- 分类筛选面板相邻行按上/下键切换时，目标行应选择与当前焦点中心横坐标最接近的筛选项。
- 第一行移动到很靠后的选项时，向下进入第二行不能机械匹配第二行同序号或末尾选项。
- 目标行选项数量少于当前行时，也要按可见横向位置找最近项。
- 继续保留筛选项获焦记忆，用于面板重新展开、从结果区返回筛选区等非相邻行场景。
- 保持左右边界抖动、横向滚动、筛选项选择回调和现有分类筛选数据不回退。
- 为分类筛选相邻行上下移动增加 widget 回归测试。

## Acceptance Criteria

- [x] 当前行聚焦到靠右的长列表选项后，向下进入相邻短行时，不落到相同序号或末尾项。
- [x] 相邻行上下移动使用当前屏幕位置最近的 chip。
- [x] 目标行无可测量候选时有稳定兜底，不抛异常。
- [x] 相关 widget test 先失败后通过。

## Notes

- 本次只调整 TV 分类筛选面板焦点导航，不改筛选数据源和分类结果加载逻辑。
