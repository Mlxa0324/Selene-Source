# Flutter TV 详情页 SSE 无播放信息提示

## Goal

Flutter TV 详情页在进入后走 SSE 后台补源时，如果等待搜索结束仍然没有查到任何可播放线路，页面上需要展示带图标的空状态提示，避免用户只看到一行普通文字，不清楚当前是“还在搜”还是“已经搜完但没有结果”。同时，当用户从搜索页进入详情页时，搜索页与详情页需要复用同一轮 SSE 搜索，不再重复发起第二次请求；若搜索页进入详情页时该轮搜索尚未结束，详情页仍需继续接收这一轮搜索的完整结果直到结束。

## Requirements

- TV 详情页进入后，仍保持现有“首个可播源优先起播 + SSE 后台补源”的加载链路不变。
- 搜索页进入详情页时，如果当前搜索页已经发起同片名 SSE 搜索，则详情页必须复用这一轮搜索结果，不再单独发起新的标题补源 SSE 请求。
- 搜索页进入详情页时，如果该轮 SSE 搜索仍在进行中，详情页需要继续接收后续增量结果和最终完整结果，直到这轮搜索结束。
- 当详情页走 SSE/增量补源流程，并且补源流程最终结束后，若页面仍没有任何可播放线路，需要展示图标 + 提示文案。
- 图标 + 提示仅针对 “SSE/增量补源流程已经结束，且最终没有任何可播放线路” 这一种场景。
- 空状态需要明显区别于普通文本占位，让用户能感知“搜索已结束，但没有查到播放信息”。
- 不影响已有的加载中状态、已有首源时的播放/换源/选集行为，以及推荐区、返回键和焦点行为。
- 相关 widget test 需要覆盖“增量搜索结束但线路为空”时的空状态展示，以及“搜索页和详情页共用同一轮 SSE 搜索”的行为。

## Acceptance Criteria

- [ ] 详情页 SSE 补源进行中时，不提前展示“搜索结束无结果”的空状态。
- [ ] 详情页 SSE 补源结束且最终没有任何可播放线路时，页面展示图标和提示文案。
- [ ] 已有至少一个可播放线路时，不展示该空状态。
- [ ] 搜索页进入详情页时，如搜索页已持有同片名 `prefetchedSources`，详情页不重复调用本地 `loadMoreSources` 标题补源。
- [ ] 搜索页进入详情页时，如原搜索页 SSE 尚未结束，详情页仍能收到后续增量结果和最终完整结果，而不是只停留在进入瞬间的快照。
- [ ] `test/tv_app/tv_video_detail_screen_test.dart` 与相关搜索页测试增加或更新回归覆盖以上场景。

## Notes

- 当前代码事实：
  - `lib/tv_app/screens/tv_video_detail_screen.dart` 的“切换线路”分区在 `sources.isEmpty` 时仅展示 `_buildEmptyText('暂无可用源')`。
  - 详情页已经区分首个可播源加载和 `loadMoreSources` 增量补源，补源入口位于 `_loadMoreSources`。
  - 详情页已经支持 `prefetchedSources`，且当该列表非空时会直接跳过本地 `loadMoreSources` 标题补源。
  - 搜索页打开详情页时，当前只会把 `_searchResults` 的即时快照筛成 `prefetchedSources` 传入详情页。
  - 这意味着如果搜索页的 SSE 仍在进行中，详情页会复用“进入瞬间的部分结果”，但不会继续接收后续增量结果，也不会再自己补发同一轮 SSE。
  - 当前未发现专门针对“SSE 搜索结束但无源”的图标空状态。
  - 现有测试已覆盖增量源先到即先展示的行为，可在此基础上补“增量补源结束但仍为空”的回归用例。
- 本任务范围：
  - 处理详情页在 SSE/增量补源结束但无线路时的图标空态提示。
  - 处理搜索页进入详情页时对同一轮 SSE 搜索的复用与补全。
  - 不调整其它“暂无可用源 / 暂无选集 / 暂无简介”文案，也不改变首源优先起播策略。
