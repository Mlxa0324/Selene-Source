当前最明显的差异

应该保留

  • 已经有独立路由壳、顶层导航分组和设计 token。
  • 已有首页 / 分类 / 详情 / 播放器模块，不是从零开始。
  • 已有 Kotlin TV 数据链路，可以把精力放在视觉复刻。

需要重点改

  • 页面壳结构不对：Kotlin 现在还有 subtitle / stats / 状态面板占位气质。
  • 顶部导航不对：按钮形状、字号、选中态、时间顺序、对齐都不像 Flutter。
  • 首页内容不对：继续观看缺少长按提示、卡片尺寸与间距偏小、层级弱。
  • 背景和留白不对：Kotlin 更黑更空，Flutter 更偏蓝灰且信息密度更高。

第一阶段你更想让我怎么推进？

我推荐先把全局壳和首页首屏做准，再扩到分类 / 详情 / 播放器，否则后面会反复返工。

A

先做首页首屏 1:1（推荐）

先把顶栏、主导航、继续观看、热门电影首屏复刻到接近 Flutter，再把这套样式扩到分类 / 详情 / 播放器。

B

先统一全局样式 token

先收敛背景、字号、按钮、圆角、间距和页面壳，再逐页补内容布局。前期看起来变化没那么惊艳，但长期更稳。

C

四个页面一起并行粗对齐

首页 / 分类 / 详情 / 播放器同时改一轮，先追求“都像一点”。速度快，但很容易出现每页像得不一样。
